# Vidya Course — Home Tuition Website

Hindi / English home tuition for Class 1–6. Shakarpur, Laxmi Nagar.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
